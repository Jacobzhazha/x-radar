# X 起量雷达

简体中文 · [English](README.en.md)

刷 X 时，在帖子时间旁显示**发出多久、多少浏览、平均每分钟多少浏览**。达到你设定的浏览量和时间阈值，帖子会加上粉色描边，方便找到刚开始起量的内容。

**[下载安装包](https://github.com/Jacobzhazha/x-radar/releases/latest/download/x-radar-v1.0.0.zip)** · [安装方法](#安装) · [设置](#设置)

## 标注效果

![X 页面中的标签与描边](docs/screenshot.jpg)

例如：`发出 37 分钟 · 1.2 万浏览 · 每分钟 324`。

默认情况下，浏览量 **≥ 5,000**、发出时间 **< 60 分钟** 的帖子会加上粉色描边。没有浏览量或有效发帖时间的帖子会跳过。

| 浏览量 | 发出时长 | 默认描边 |
| --- | --- | --- |
| 12,000 | 37 分钟 | 是 |
| 3,014 | 10 分钟 | 否 |
| 99,000 | 60 分钟 | 否 |

## 安装

1. 下载上面的安装包，解压得到 `x-radar` 文件夹。
2. 在 Chrome 地址栏输入 `chrome://extensions`，打开右上角的「开发者模式」。
3. 点击「加载已解压的扩展程序」，选择包含 `manifest.json` 的 `x-radar` 文件夹。
4. 打开或刷新 X。插件会自动处理当前页面，以及滚动后加载的帖子。

也可以选择 **Code → Download ZIP** 下载源码，解压后加载仓库里面的 `x-radar` 子文件夹。无需 Node.js、构建步骤或 API Key。

加载后保留这个文件夹。更新时替换其中的文件，在扩展管理页点击插件的重新加载按钮，再刷新 X 页面。

## 设置

点击浏览器右上角的拼图图标，将「X 起量雷达」固定到工具栏，再点击它打开设置。

<img src="docs/popup.png" alt="X 起量雷达设置面板" width="288">

| 设置项 | 默认值 | 作用 |
| --- | --- | --- |
| 总开关 | 开启 | 显示或隐藏所有标签和描边 |
| 浏览数阈值 | 5,000 | 达到此浏览量才描边 |
| 分钟数阈值 | 60 | 发出时间小于此分钟数才描边 |

修改后自动保存到本机。面板也会显示当前页面的描边数量。

## 浏览量怎么算

浏览量取自 X 页面上的显示值，支持 `1.2万`、`1.6亿`、`12K`、`1.2M`、`2B` 和 `3,014` 等写法。

「每分钟」按**当前浏览量 ÷ 已经过的整分钟数**计算，结果向下取整；不足一分钟按一分钟计算。X 显示的是约数时，计算结果也是约数。

插件每 30 秒重算帖子时长，并处理页面中新加载或更新的内容；浏览量跟随 X 页面显示值变化。

## 代码

- `x-radar/`：可直接加载的插件文件。
- `x-radar-tests/`：逻辑测试与浏览器测试脚本。
- [开发说明](docs/DEVELOPMENT.md)：文件结构和测试命令。

插件使用 Manifest V3，只申请 `storage` 权限，在 `x.com` 和 `twitter.com` 上运行。设置通过 `chrome.storage.local` 保存在本机；插件没有后台脚本，也不发起网络请求。
